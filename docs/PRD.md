# 문제 정의서: 병원 플랫폼 입점 가능성 예측 기반 영업 리드 발굴·제안

분석 시작 전에 정리한 설계 문서입니다 (2026-11-24). 실제 진행과 결과는 README와 `outputs/experiment_notes.md`에 있습니다.

## 개요

**상황 가정:** 병원 가격·리뷰 플랫폼은 광고하는 병원(입점 병원)을 늘려야 매출이 커진다. 영업 담당자가 만날 수 있는 병원 수는 한정되어 있다.

**문제:** 서울에만 안과 의원이 수백 곳이다. 어느 병원부터 찾아가야 계약 가능성이 높은지를 감이 아니라 데이터로 정하고 싶다.

**가설**

- H1. 이미 입점한 병원은 개원 연차, 규모, 경쟁 밀도, 수술실 보유 같은 공개 데이터 특성에서 미입점 병원과 차이가 있다.
- H2. 입점 병원과 닮은 미입점 병원을 먼저 찾아가면, 무작위로 고를 때보다 계약 가능성이 높다.
- H3. 병원별 손익분기 예약 건수를 담은 제안서는 일반 소개서보다 설득력이 높고, AI 에이전트로 일관되게 만들 수 있다.

**만들 것:** (1) 입점 가능성 점수 모델, (2) 우선 방문 대상 Top 30, (3) 병원별 ROI 제안서를 만드는 에이전트.

## 성공 지표

핵심 지표는 "모델이 고른 상위 20%에 실제 입점 병원이 무작위보다 몇 배 많이 들어 있는가"다. 입점 병원이 전체의 일부라, 전부 미입점이라고만 찍어도 정확도가 높게 나오므로 정확도는 쓰지 않는다.

| 지표 | 정의 | 무작위 기준 | 목표 |
| --- | --- | --- | --- |
| 상위 20% 정밀도 | 점수 상위 20% 병원 중 실제 입점 비율 | 전체 입점 비율 | 무작위의 2배 이상 |
| 무작위 대비 배수 (lift) | 상위 20% 정밀도 ÷ 전체 입점 비율 | 1.0배 | 2.0배 이상 |
| 상위 20% 포착률 | 전체 입점 병원 중 상위 20%에 들어간 비율 | 20% | 40% 이상 |

- 모든 모델 지표는 5-fold 교차검증 결과로 계산한다. 학습에 쓴 데이터로 채점하지 않는다.
- 목표에 못 미쳐도 결과는 그대로 보고하고, 어떤 특성이 입점과 관련 있었는지 함께 보여 준다.

## 범위와 데이터

- **포함:** 서울 안과 의원, 공개 데이터, 플랫폼 공개 목록으로 확인한 입점 여부
- **제외:** 다른 진료과, 실제 병원 연락·영업, 플랫폼의 비공개 내부 데이터(광고 매출·계약 기록 등, 접근 불가)

| 데이터 | 출처 | 쓸 항목 |
| --- | --- | --- |
| 기본정보 | [전국 병의원 및 약국 현황](https://www.data.go.kr/data/15051059/fileData.do) (심평원) | 요양기관명, 종별, 주소, 개설일자, 총의사수, 홈페이지, 좌표 |
| 진료과목정보 | 같은 묶음 | 진료과목코드명, 과목별 전문의수 |
| 시설정보 | 같은 묶음 | 수술실병상수 |
| 교통정보 (선택) | 같은 묶음 | '역 근처' 가설용 |
| 비급여 진료비 (선택) | 심평원 비급여 공개 | 시술 항목 가격 신고 여부 |
| 입점 여부 (정답) | 병원 플랫폼의 안과 공개 목록 | 병원명, 지역, 제휴 여부 |

**입점 판단 기준:** 플랫폼 목록에는 제휴하지 않은 병원도 올라와 있을 수 있으므로, 목록 존재 여부가 아니라 제휴 표시로 입점(1)을 판단한다. 이름이 정확히 맞지 않는 병원은 지역·주소로 직접 확인하고, 끝내 애매하면 '보류'로 두고 모델에서 뺀다.

**수집 원칙**

- 공개 목록은 이용약관과 robots.txt를 확인한 뒤, 로그인 없이 저속으로 수집하고 병원명·지역·제휴 여부만 저장한다. 비정상 응답이 나오면 우회하지 않고 멈춘다.
- 실제 병원에 연락하거나 견적을 신청하지 않는다.
- 공개 산출물에는 병원명을 익명(예: 강남구 A안과)으로 표시한다.

## 분석·모델 설계

입점 병원은 수십 곳 수준일 것이므로, 변수는 4~6개로 제한하고 해석하기 쉬운 로지스틱 회귀를 쓴다.

| 특성 변수 | 만드는 방법 | 기대 방향 (가설) |
| --- | --- | --- |
| 개원 연차 | 2026년 − 개설연도 | 개원 초기 병원이 환자 확보를 위해 입점 |
| 규모 | 안과 전문의 수 | 규모가 클수록 광고 예산 여력 |
| 수술실 보유 | 수술실병상수 > 0 | 시력교정·백내장 같은 수술을 하는 병원이 가격 비교 플랫폼과 잘 맞음 |
| 경쟁 밀도 | 좌표로 계산한 반경 1km 안과 수 | 경쟁이 심할수록 차별화 마케팅 필요 |
| 홈페이지 보유 (후보) | 홈페이지 값 있음 | 온라인 마케팅에 적극적인 병원 |
| 역까지 거리 (후보) | 교통정보의 거리 | 역 근처 병원 |

**순서:** 입점/미입점 특성 비교 → 다중공선성(VIF) 확인 → 로지스틱 회귀(클래스 불균형 보정, L2 규제) → 층화 5-fold 교차검증 → 지표 계산 → 전체 데이터로 다시 학습해 미입점 병원에 점수 → 계수(오즈비)로 해석.

## 실험 방식 (가설 → 실행 → 검증 → 반영)

처음 가설로 모델을 돌리고, 모델이 틀린 병원을 직접 들여다보며 새 가설을 세워 다시 돌린다.

- 사이클 1: 처음 가설(개원 초기·경쟁 심함·규모 큼·수술실 있음)로 돌리고, 방향이 반대이거나 효과가 불확실한 변수는 뺀다.
- 사이클 2: 모델이 틀린 병원을 골라 직접 보고 공통점에서 새 가설을 세운다.
- 판단 규칙: 배수가 오르면 채택, 차이가 작으면 우연일 수 있으니 단순한 모델을 유지한다. 기각한 가설도 이유를 남긴다.
- 검증 범위: "입점한 병원과 닮은 병원을 무작위보다 잘 찾는가"까지다. 실제 계약 여부는 방문·미팅 결과로 다시 학습해야 알 수 있다.

## 제안서 에이전트와 ROI

Top 30 중 한 병원을 고르면 1페이지 맞춤 제안서가 나온다. 숫자는 모두 코드가 계산하고, AI는 그 숫자만 보고 문장을 쓴다.

- 구성: 지역 현황, 추천 상품과 이유, 손익분기 예약 건수, 미팅에서 확인할 질문 2개
- 손익분기 예약 건수 = 월 광고비 ÷ (시술가 × 공헌이익률)

| 가정값 | 기본값 | 근거 |
| --- | --- | --- |
| 시술가 (라섹) | 70만원 | 공개된 시력교정 이벤트 가격대 참고 (가정) |
| 공헌이익률 | 50% | 가정, 민감도 30~60% 함께 표시 |
| 월 광고비 | 100만원 | 가정, 실제 단가는 알 수 없음 |

- 모든 가정값은 "(가정)"으로 표시하고, 실제 값을 넣으면 바로 다시 계산되게 한다.
- 환자 1명당 수수료 구조는 의료법상 환자 알선 논란이 있어 정액 광고 기준으로만 계산한다.
