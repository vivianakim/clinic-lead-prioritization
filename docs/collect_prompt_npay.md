# 심평원 비급여 진료비용 — 서울 안과 수술 항목 병원 목록 수집 프롬프트

```text
[목적]
심평원 '비급여 진료비용 정보' 상세검색에서 서울 의료기관 중 안과 수술 비급여 항목(시력교정술, 백내장, 노안 등)을
신고한 병원 목록을 모아 CSV로 저장해줘. 병원별로 "어떤 수술 항목을 신고했는지"만 필요하고, 가격 분석은 하지 않아.

[페이지]
https://www.hira.or.kr/npay/index.do?pgmid=HIRAA030009000000#app%2Frb%2FnpayDamtInfoList
- 왼쪽 '항목으로 조회하기' → 1. 지역: 시/도 = 서울, 시/군/구 = 전체
- 2. 의료기관 규모: 전체
- 3. 비급여 진료비 항목: 항목명 검색창에 키워드 입력 → 검색 → 상세분야 팝업에서 항목 체크 → '선택항목 검색'
- 결과 표 컬럼: 의료기관명, 의료기관규모, 소재지, 중분류, 소분류, 상세분류, 최소금액, 최대금액
- 오른쪽 위 'N개씩 보기'를 가장 큰 값으로 바꾸면 페이지 수를 줄일 수 있어.

[검색할 항목] — 키워드별로 상세분야 팝업에 나오는 항목을 모두 확인하고, 안과 수술 항목만 골라줘
1. 시력교정술: 레이저각막절삭성형술(라식), 레이저각막상피절삭성형술(라섹) — 서울 합계 약 209건으로 보임
2. 백내장: 다초점 인공수정체, 백내장 관련 비급여 항목
3. 노안: 노안 교정 관련 항목
4. 그 외 팝업에서 보이는 안과 수술 항목(예: 렌즈삽입술/유수정체 안내렌즈, 각막 관련 수술)이 있으면 포함
- 각 키워드에서 실제로 선택한 상세 항목명을 기록해줘.

[저장] data/raw/hira_npay/hira_npay_seoul_eye_YYYYMMDD.csv (UTF-8, 확인한 날짜로)
컬럼: 검색키워드, 의료기관명, 의료기관규모, 소재지, 중분류, 소분류, 상세분류
- 가격(최소·최대금액)은 저장하지 않아.
- 한 병원이 여러 항목을 신고했으면 항목마다 한 줄 (중복 제거는 내가 함).

[수집 규칙]
- robots.txt 확인됨: /co/ 만 Disallow. /npay/ 는 허용.
- 로그인 없이 공개 화면만. 화면 조작(클릭·페이지 넘김) 사이 간격 3초 이상.
- 내부 API를 직접 호출하지 말고, 화면에 보이는 결과만 읽어.
- 403, 캡차, 접속 차단, 비정상 응답이 나오면 우회하지 말고 즉시 멈추고 알려줘.
- 알림창(alert)이 뜨면 문구를 기록하고 멈춰.

[끝나면 보고]
- 키워드별: 선택한 상세 항목명, 화면에 표시된 '검색결과 총 N건', 실제 저장한 행 수 (일치 여부)
- 의료기관규모별 건수 (의원 / 병원 / 종합병원 등)
- 확인 날짜, 막힌 곳이 있었다면 그 내용
```
