# 샘플 데이터

`platform_listing_sample.csv`는 `src/00_collect_partners.py`가 만드는 `data/raw/platform_listing.csv`와 같은 열 구조를 보여 주는 **가짜 데이터**입니다. 병원명과 id는 지어낸 값이고 실제 병원이 아닙니다.

| 열 | 뜻 |
| --- | --- |
| id | 플랫폼의 병원 id |
| 병원명 | 병원 이름 |
| 시·구·동 | 주소의 행정구역 |
| is_partner | 플랫폼 제휴(입점) 여부. 1이면 입점 |
| 확인일 | 목록을 확인한 날짜 |

실제 분석에는 심평원 공공데이터(README의 다운로드 링크)와 직접 수집한 공개 목록을 씁니다. 원본은 저장소에 올리지 않습니다.
